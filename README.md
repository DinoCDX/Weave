# WeaveEngineX

A Rust game engine for 3D games on desktop, built around efficiency and explicit control. Windows first, Linux second.

Status: Pre Alpha

## Build

Requires the toolchain pinned in `rust-toolchain.toml`. Running any cargo command installs it automatically through rustup.

```
cargo build --workspace
cargo test --workspace
cargo run -p triangle
```
